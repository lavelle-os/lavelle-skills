# Test prompts

The exact text given to the model for each test run in [TEST-LOG.md](../TEST-LOG.md), one file per run, named by date and skill: `2026-11-05-receptionist.md`. The log entry links to its file. With the file you can repeat the run word for word on your own model and compare what you get with what the log says happened.

Runs before 2026-11-04 have no file here. Their prompts were not kept, and the log describes each request in a sentence or two instead. An outside code review asked for this folder on 2026-11-04.

Every name, number and business in these prompts is made up, the same as in the log.
